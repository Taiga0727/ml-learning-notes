# Data

Source: Kaggle **Spider, Scorpion, Cockroach** dataset by Mathew Ribeiro, `mathewribeiro/spiderscorpioncochroach` (the notebook downloads it with `kagglehub`; about 90 MB). Not redistributed here; check the dataset's licence on Kaggle.

| Stage | Folder (Drive) | Content |
|---|---|---|
| 0 | `SVM/train` | the Kaggle training photos: scorpions 367, cockroaches 303, spiders 328 |
| 1 | `SVM/Data` | 300 random photos per class |
| 2 | `SVM/Data224` | spiders and scorpions only, augmented to 3,000 per class at 224x224 |
| 3 | `SVM/Datasplit/{train,val,test}` | 70 / 20 / 10 split of stage 2 (seed 69): 4,200 / 1,200 / 600 images |

Stages 1 to 3 are regenerated by the notebook, so no images are stored in this repository.
